# Fortnite TCG

A solo-first, browser-based collectible card game inspired by Fortnite cosmetics.

## Current project choices

- **Platform:** Web
- **Visual direction:** Custom card-game interface
- **Game mode:** Solo first
- **Cosmetic data:** Hybrid (API-backed data plus curated local entries)
- **Card art:** Cosmetic images sourced from Fortnite.GG where permitted; the game uses its own card frames and interface.

## Planned cosmetic categories

Outfits, back blings, pickaxes, gliders, emotes, sidekicks, and kicks.

## Planned systems

- Collection and duplicate tracking
- Seven-card packs with one-at-a-time reveals
- Item Shop rotation
- Battle Pass-style progression and achievements
- Local auto-save with validated JSON export/import
- Cosmetic styles represented as separate cards

## Development

```bash
npm install
npm run dev
```

## Technology

React, TypeScript, Vite, Zustand, IndexedDB, and Lucide icons.
